Политика конфиденциальности

Приложение «secretary». Редакция от 18 сентября 2026 года.

1. Кто обрабатывает данные

Приложение «secretary» — внутренний инструмент, который использует и обслуживает владелец аккаунта Google, подключившего приложение. Приложение работает на собственном сервере владельца. Отдельной компании-оператора, собирающей данные пользователей, здесь нет.

2. Какие данные используются

Приложение обращается только к данным того аккаунта Google, который сам дал на это разрешение, и только к тем сервисам, доступ к которым был подтверждён на экране согласия Google:

  • события и настройки календаря;
  • содержимое таблиц, документов и файлов на Диске;
  • письма в Почте;
  • проекты Google Apps Script.

Приложение не собирает данные третьих лиц, не покупает и не получает данные из сторонних источников.

3. Зачем данные используются

Исключительно для того, чтобы выполнить запрос самого владельца аккаунта: показать расписание, найти или подготовить документ, внести запись в таблицу, прочитать или отправить письмо.

Данные не используются для рекламы, для обучения моделей и для построения профилей пользователей.

4. Кому данные передаются

Данные не продаются и не передаются третьим лицам. Передача происходит только в двух случаях:

  • обращение к самим API Google — чтобы получить или изменить запрошенные данные;
  • обращение к поставщику языковой модели, который формирует ответ помощника, — в объёме, необходимом для выполнения конкретного запроса.

Использование данных Google соответствует Политике Google API Services User Data Policy, включая требования Limited Use.

5. Где и сколько хранятся данные

Токены доступа Google хранятся в защищённом виде на сервере владельца и используются только для обращения к перечисленным сервисам. Содержимое писем, документов и событий постоянно не хранится: оно запрашивается в момент выполнения задачи. Рабочая переписка с помощником хранится на том же сервере.

6. Как отозвать доступ

Доступ можно отозвать в любой момент на странице Доступ сторонних приложений в настройках аккаунта Google. После отзыва приложение теряет возможность обращаться к данным, а сохранённые токены становятся недействительными и удаляются.

7. Изменения

Изменения этой политики публикуются на этой же странице с указанием новой даты редакции.
